# RedTecniHogar — Página Web de Servicios

Página web desarrollada para **RedTecniHogar**, una empresa dedicada a ofrecer servicios de mantenimiento, reparación, remodelación y mejoras para hogares y negocios.

El proyecto fue desarrollado con **WordPress**, utilizando **Elementor, HTML y CSS**, junto con diferentes plugins para incorporar funcionalidades de contacto y mejorar la experiencia del usuario.

## 🌐 Proyecto

**Sitio web:** https://redtecnihogar.com/

La página permite a los usuarios conocer los diferentes servicios ofrecidos y comunicarse directamente con la empresa para solicitar información o una cotización.

## 🛠️ Tecnologías utilizadas

* **WordPress** — Gestión y desarrollo del sitio web.
* **Elementor** — Diseño y construcción visual de las diferentes secciones.
* **HTML** — Estructuración y personalización del contenido.
* **CSS** — Estilos, diseño visual y ajustes personalizados.
* **Plugins de WordPress** — Integración de funcionalidades adicionales.
* **WhatsApp** — Canal de comunicación directa con los clientes.
* **Correo electrónico** — Recepción de solicitudes y mensajes.

## ✨ Características

* Diseño moderno y orientado a la presentación de servicios.
* Diseño **responsive**, adaptado a computadores, tablets y dispositivos móviles.
* Navegación mediante diferentes secciones del sitio.
* Presentación organizada de los servicios.
* Integración con **WhatsApp** para facilitar el contacto.
* Integración con **correo electrónico**.
* Sección informativa sobre la empresa.
* Sección para solicitar cotizaciones.
* Interfaz enfocada en facilitar el contacto entre los clientes y la empresa.

## 🔧 Servicios presentados

Entre los servicios disponibles en el sitio se encuentran:

* Reformas y acabados.
* Servicios eléctricos.
* Plomería.
* Aire acondicionado.
* Soldadura.
* Divisiones de baño.
* Carpintería en madera.
* Calentadores y gas.
* Desarrollo de software.

## Diseño Responsive

El sitio fue diseñado para ofrecer una experiencia de navegación adaptable a diferentes tamaños de pantalla, permitiendo consultar los servicios y utilizar las opciones de contacto desde dispositivos móviles, tablets y computadores.

## Objetivo del proyecto

El objetivo principal fue desarrollar una presencia web profesional para la empresa, permitiendo **mostrar sus servicios, facilitar el contacto con clientes potenciales y centralizar la información de la empresa en un sitio web accesible y moderno**.

## Desarrollo

Proyecto desarrollado como solución web para una empresa real, utilizando herramientas de desarrollo y personalización sobre WordPress.

**Tecnologías:** WordPress · Elementor · HTML · CSS · Plugins · Responsive Web Design
